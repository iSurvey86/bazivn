# MASTER PROJECT SPECIFICATION: MULTILINGUAL METAPHYSICS SAAS
**Project Type:** Next.js Full-stack SaaS Platform
**Domain:** Eastern Metaphysics (BaZi, Numerology, ZeRi Calendar)
**Core Features:** High-precision astronomical calculation, Hybrid AI Multilingual Generation, Paywall with Localized Pricing, Automated Push Notifications.

## 1. TECH STACK
- **Framework:** Next.js 14+ (App Router), React, Tailwind CSS.
- **UI Library:** shadcn/ui.
- **Database & Auth:** Supabase (PostgreSQL, Realtime, pg_cron).
- **AI Engine:** Vercel AI SDK (`ai`), OpenAI/Gemini APIs.
- **Internationalization (i18n):** `next-intl` (Locales: `vn`, `en`, `zh`, `ko`).
- **Astrology Engine:** `lunar-typescript` (by 6tail).
- **Payments:** Stripe (Global/Dynamic Pricing) + PayOS/MoMo (Vietnam Local).
- **Notifications:** Telegram Bot API / Zalo ZNS.

## 2. SYSTEM ARCHITECTURE & CORE LOGIC

### A. The Calculation Engine (`lib/astrology-engine`)
MUST execute strictly on the Server-Side to ensure astronomical accuracy.
- **Dependency:** `lunar-typescript`.
- **Timezone Handling:** Convert user input to local birth timezone before calculation.
- **Late Rat Hour Rule (Dạ Tý - 23:00 to 00:00):** STRICT RULE. If the user is born between 23:00 and 23:59, the **Day Pillar MUST remain the current day**, but the **Hour Pillar MUST advance to the next day (Zi hour)**. Do NOT roll over the entire date.
- **Solar Terms (Tiết Khí):** Exact minute precision. Month pillar shifts only if the birth time passes the exact transition minute.

### B. Hybrid AI Multi-language System
- **Concept:** Do not store full translated texts. Store core terminology in DB (`JSONB`) and inject into dynamic AI prompts.
- **AI Prompt Structure (3 Layers):**
  1. Persona (Expert, empathetic, natural metaphors).
  2. Core Data (Exact terminology mapped from DB based on selected locale).
  3. Task (Write an analysis for Career/Relationships in the target language).
- **Streaming & Caching:** Use Vercel AI SDK to stream text to the frontend. On finish, save the output to `ai_readings_cache` (tied to `chart_id` and `locale`). Next time, load instantly from cache.

### C. Paywall & Real-time Unlock
- **Localized Pricing:** Read `x-vercel-ip-country` header. Show VND for VN, USD for US/Global, KRW for KR.
- **Webhook Security (Strict):**
  1. Verify Signature (HMAC/Secret Key).
  2. Validate `Amount >= Premium Price`.
  3. Idempotency Check: Ignore if order is already processed.
- **Realtime UI:** Use Supabase Realtime WebSocket on the `user_charts` table. When `is_premium` becomes `true` via webhook, the frontend automatically removes the blur/lock overlay and triggers the AI stream.

### D. Cron Jobs & Automated Notifications (Retention System)
- Use Supabase `pg_cron` and `pg_net` to trigger Next.js API endpoints.
- **Cron 1 (1st & 15th of the Month):** Trigger AI to generate personalized monthly updates based on the user's BaZi and send via Telegram/Zalo.
- **Cron 2 (Daily Event Reminder):** Scan `user_saved_events` for tomorrow's events and send reminders.

## 3. DATABASE SCHEMA (SUPABASE POSTGRES)
Implement the following SQL schema:

```sql
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS pg_cron;
CREATE EXTENSION IF NOT EXISTS pg_net;

-- 1. CORE TERMS (Dictionary)
CREATE TABLE public.core_terms (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

    names JSONB NOT NULL -- e.g., {"vn": "Canh Kim", "en": "Geng Metal"}

-- 2. USER CHARTS (Master Records)
CREATE TABLE public.user_charts (

    user_id UUID REFERENCES auth.users(id) ON DELETE SET NULL,
    full_name VARCHAR(100) NOT NULL,
    birth_time_utc TIMESTAMP WITH TIME ZONE NOT NULL,
    bazi_data JSONB, -- Storing the calculated pillars & Day Master
    numerology_data JSONB,
    is_premium BOOLEAN DEFAULT FALSE,
    order_id VARCHAR(100),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()

-- 3. AI READINGS CACHE
CREATE TABLE public.ai_readings_cache (

    chart_id UUID REFERENCES public.user_charts(id) ON DELETE CASCADE,
    lang_code VARCHAR(5) NOT NULL,

    notify_1st_15th BOOLEAN DEFAULT TRUE,
    preferred_channel VARCHAR(20) DEFAULT 'telegram',
    channel_contact_id VARCHAR(100)

CREATE TABLE public.user_saved_events (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,

**Tính năng Cốt lõi:** Thuật toán thiên văn độ chính xác cao, Trí tuệ nhân tạo (AI) Lai Đa ngôn ngữ, Cổng thu phí với Giá động theo khu vực, Hệ thống Thông báo Đẩy Tự động.

## 1. CÔNG NGHỆ SỬ DỤNG (TECH STACK)

- **Thư viện Giao diện (UI):** shadcn/ui.

## 2. KIẾN TRÚC HỆ THỐNG & LOGIC CỐT LÕI

### A. Lõi Tính toán (`lib/astrology-engine`)
BẮT BUỘC thực thi hoàn toàn trên Server-Side (Máy chủ) để đảm bảo độ chính xác thiên văn.
- **Thư viện phụ thuộc:** `lunar-typescript`.
- **Xử lý Múi giờ:** Phải chuyển đổi ngày giờ nhập liệu của người dùng về đúng múi giờ địa phương nơi sinh trước khi đưa vào tính toán.
- **Quy tắc Giờ Dạ Tý (23:00 - 00:00):** QUY TẮC NGHIÊM NGẶT. Nếu người dùng sinh trong khoảng từ 23:00 đến 23:59, **Trụ Ngày BẮT BUỘC giữ nguyên ngày hiện tại**, nhưng **Trụ Giờ BẮT BUỘC bước sang ngày tiếp theo (Giờ Tý)**. Tuyệt đối KHÔNG ĐƯỢC làm tròn/đẩy toàn bộ ngày sinh sang ngày hôm sau.
- **Tiết Khí:** Tính toán chính xác đến từng phút. Trụ tháng chỉ được phép đổi sang tháng mới nếu thời gian sinh thực tế vượt qua phút giao tiết khí.

### B. Hệ thống AI Lai Đa ngôn ngữ (Hybrid AI)
- **Khái niệm:** Không lưu trữ toàn bộ văn bản dịch sẵn. Chỉ lưu các thuật ngữ chuyên môn cốt lõi vào Database (dạng `JSONB`) và tiêm (inject) vào các câu lệnh AI động (Dynamic Prompts).
- **Cấu trúc Prompt AI (3 Lớp):**
  1. Vai trò (Chuyên gia, thấu cảm, dùng nhiều hình ảnh ẩn dụ tự nhiên).
  2. Dữ liệu Lõi (Thuật ngữ chuyên môn chính xác được trích xuất từ DB dựa trên ngôn ngữ người dùng chọn).
  3. Nhiệm vụ (Yêu cầu AI viết bài phân tích về Sự nghiệp/Tình duyên bằng ngôn ngữ đích).
- **Streaming & Caching (Đổ chữ & Lưu đệm):** Dùng Vercel AI SDK để hiển thị chữ chạy ra màn hình frontend theo thời gian thực. Khi viết xong, lưu kết quả vào bảng `ai_readings_cache` (gắn với `chart_id` và mã ngôn ngữ). Ở lần truy cập sau, hệ thống tải kết quả ngay lập tức từ bộ nhớ đệm này.

### C. Cổng thu phí (Paywall) & Mở khóa Thời gian thực
- **Giá động theo khu vực:** Đọc biến `x-vercel-ip-country` trên Header. Hiển thị VNĐ cho khách VN, USD cho khách Quốc tế, KRW cho khách Hàn Quốc.
- **Bảo mật Webhook (Quy định nghiêm ngặt):**
  1. Xác thực Chữ ký số (HMAC/Secret Key).
  2. Kiểm tra tính hợp lệ: `Số tiền nhận được >= Giá gói Premium`.
  3. Kiểm tra tính Lũy đẳng (Idempotency): Bỏ qua tín hiệu nếu đơn hàng này đã từng được xử lý thành công trước đó (chống giả mạo/gửi lặp).
- **Giao diện Thời gian thực (Realtime UI):** Dùng Supabase Realtime WebSocket trên bảng `user_charts`. Ngay khi Webhook chuyển `is_premium` thành `true`, frontend tự động gỡ bỏ các lớp mờ (blur/lock) và kích hoạt AI viết tiếp các Module Premium.

### D. Cron Jobs & Hệ thống Nhắc nhở Tự động (Tối ưu Retention)
- Sử dụng extension `pg_cron` và `pg_net` của Supabase để tự động gọi (trigger) các API trên Next.js.
- **Cron 1 (Mùng 1 & 15 hàng tháng):** Kích hoạt AI tạo thông điệp vận trình tháng được cá nhân hóa theo Bát tự và tự động gửi qua Telegram/Zalo.
- **Cron 2 (Nhắc sự kiện hàng ngày):** Quét bảng `user_saved_events` để tìm các sự kiện (ví dụ: ngày tốt khai trương) diễn ra vào ngày hôm sau và gửi tin nhắn nhắc lịch.
